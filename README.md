## How to Compile and Run

1. Open **CMD** and navigate to the project directory.

2. Compile the program using:

   `g++ -std=c++17 -Wall -Wextra main.cpp Marquee.cpp -o csopesy.exe`

3. Run the program using:

   `csopesy.exe`
